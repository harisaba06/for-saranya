SARANYA SORRY WEBSITE

1. Open index.html in a browser to preview.
2. To publish free with GitHub Pages:
   - Create a new public GitHub repository.
   - Upload index.html to the repository root.
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Select main and /(root), then Save.
   - After publishing, share the Pages URL with Saranya.

To personalize:
- Edit the apology paragraphs and signature in index.html.
- Change the title in the <title> tag if desired.
- This is a single-file website. No frameworks or paid assets are required.
